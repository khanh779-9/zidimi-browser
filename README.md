A fast, modern, and privacy-respecting desktop web browser built on top of the Chromium engine. Designed with a sleek, minimalist user interface and packed with productivity features, Heco Browser provides a seamless browsing experience.

## Key Features

### Modern & Customizable UI
* **Sleek Interface**: Clean, pill-shaped design language with smooth animations and interactive popups.
* **Themes**: Fully supports Light and Dark modes. The interface adapts to your system preferences or can be customized manually.
* **Custom Zoom & Fonts**: Configure default zoom levels and adjust font sizes for optimal readability.

### Fast & Secure Browsing
* **Chromium Engine**: Powered by the reliable Chromium Embedded Framework (CEF), ensuring fast page loads and modern web compatibility.
* **Security Indicators**: Clear visual indicators for HTTPS (secure), HTTP (not secure), and internal pages.
* **Privacy Controls**: Built-in support for blocking third-party cookies, sending "Do Not Track" requests, and Safe Browsing.

### Profile & Guest Mode
* **Multi-Profile Support**: Create and manage multiple user profiles. Keep your work and personal browsing data completely separate.
* **Guest Mode**: Instantly switch to Guest Mode for a temporary session. No browsing history, cookies, or site data are saved once you close the session.

### Smart Omnibox & Search
* **Intelligent Address Bar**: Get instant suggestions from your history, bookmarks, and search engine as you type.
* **Multiple Search Engines**: Choose your preferred default search engine (Google, Bing, DuckDuckGo, Brave Search).
* **Find in Page**: Quickly search for text within any webpage (Ctrl + F).

### Multi-Language Support
* **Dynamic Localization**: Switch the browser's interface language on the fly without needing to restart.
* **Supported Languages**: English, Vietnamese, and Simplified Chinese.

### Productivity Tools
* **Bookmarks & History**: Easily save, organize, and search your favorite pages and browsing history.
* **Download Manager**: Track your active downloads and manage downloaded files directly from the built-in Downloads page.
* **Data Manager**: Securely store and manage your passwords, payment methods, and addresses for auto-filling.

## Getting Started (How to Use)

### Navigation & Shortcuts
Heco Browser supports standard browser keyboard shortcuts to keep you productive:

| Shortcut | Action |
| --- | --- |
| **Ctrl + T** | Open a new tab |
| **Ctrl + W** | Close the current tab |
| **Ctrl + Tab** / **Ctrl + Shift + Tab** | Cycle through open tabs |
| **Ctrl + 1-9** | Jump to a specific tab |
| **Ctrl + L** | Focus the address bar |
| **Ctrl + F** | Find in page |
| **Ctrl + D** | Bookmark the current page |
| **F5** or **Ctrl + R** | Reload page |
| **Ctrl + + / - / 0** | Zoom In / Zoom Out / Reset Zoom |
| **F11** | Toggle Fullscreen |
| **F12** | Open Developer Tools |

### Managing Profiles & Data
1. Click the Avatar icon on the right side of the address bar.
2. Toggle Guest Mode for private browsing, or click Manage Profiles to add/switch user profiles.
3. To manage your saved passwords, cards, or browsing data, click the Menu (≡) > Preferences > Autofill.

### Customizing the Browser
* Open the Preferences page via the Menu (≡) or by pressing Ctrl + ,.
* **Change Language**: Go to the Languages tab and select your preferred display language. The UI will update instantly.
* **Change Theme**: Navigate to the Appearance tab to switch between Light, Dark, or System default themes.
* **Clear Data**: Go to the Privacy and security tab to quickly wipe your history, cookies, and cache.
